# コンペ整理メモ：木材近赤外スペクトルによる含水率予測

作成: 2026-04-17

---

## コンペ概要

| 項目     | 内容                       |
| -------- | -------------------------- |
| タスク   | 回帰（木材の含水率を予測） |
| 評価指標 | RMSE（小さいほど良い）     |
| 提出上限 | 最大2件を最終評価に選択    |
| 入賞枠   | 上位6名                    |

### 含水率の定義

```
含水率(%) = (水の質量 / 全乾状態の木材質量) × 100
```

---

## データ構造

### カラム構成

| カラム                   | 説明                              |
| ------------------------ | --------------------------------- |
| sample number            | サンプル通し番号                  |
| species number           | 樹種番号                          |
| 樹種                     | 樹種名                            |
| 含水率                   | 目的変数（trainのみ）             |
| 9993.76781 〜 3999.82139 | 波数ごとの近赤外吸光度（約750列） |

### データサイズ

- エンコーディング: **shift-jis**
- スペクトル列数: 約750波数列（10000〜4000 cm⁻¹、8 cm⁻¹分解能）

---

## ⚠️ 最重要発見：trainとtestの樹種が完全に異なる

| データ         | 樹種（13種）                                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **train only** | イチョウ、ウエンジ、ウォールナット、クリ、スプルース、チェリー、トチ、ナラ、ヒノキ、ベイスギ、ベイマツ、ホワイトオーク、米ヒバ |

| データ        | 樹種（6種）                                      |
| ------------- | ------------------------------------------------ |
| **test only** | クスノキ、ケヤキ、スギ、タモ、チーク、ヤマザクラ |

- **train と test に共通する樹種はゼロ**
- → `species number` 特徴量はtestに対して意味をなさない
- → **樹種をまたいで汎化できる特徴量が必要**（ゼロショット汎化問題）

---

## ルール整理

### 許可されていること

1. **配布データの画像（fig1・fig2）の利用**
   - trainデータに対応する範囲に限り特徴量として利用可能
2. **汎用オープンソースモデルの利用**
   - 事前学習済みモデルを重みを変えずにそのまま利用すること
3. **モデルによる特徴量化**
   - 樹種名などを事前学習済みモデルで埋め込みに変換し、スペクトルと組み合わせて予測に使うこと

### 禁止されていること

1. **評価用データの画像利用**
   - testに対応する樹種（クスノキ、ケヤキ、スギ、タモ、チーク、ヤマザクラ）の画像利用
2. **画像からの情報抽出**
   - 画像から色・木目等の情報を手動で抽出し予測時の入力特徴量として利用すること
   - → **RGBやHSVの手動抽出はNG**
3. **外部知識の収集・利用**
   - Wikipedia等から樹種情報（密度・産地・材質）を取得して特徴量化すること
4. **オープンウェイトモデルの追加学習・ファインチューニング**
5. **外部知識の注入**（汎用モデル利用の枠を超えた外部知識の取り込み）

### ルール判断基準

> 「未知スペクトルが1つだけ与えられた状況でも実行可能か？」  
> Yes → 可 / No（複数のtestデータが必要）→ 禁止

## NIRスペクトルの特性と前処理

### スペクトルに生じるノイズ・変動要因

- 散乱（粒径・表面状態の違い）
- プローブ〜試料間距離の変化（乾燥収縮による）
- ベースラインのオフセット・傾き

### 前処理の選択肢

| 手法                                     | 効果                                        | 実装状況                                  |
| ---------------------------------------- | ------------------------------------------- | ----------------------------------------- |
| SNV（Standard Normal Variate）           | 行単位の標準化。散乱・光路長変動を補正      | ✅ 実装済み                               |
| SG 2次微分（Savitzky-Golay）             | ベースラインのオフセット・傾きを除去        | ✅ 実装済み（window=11, poly=2, deriv=2） |
| MSC（Multiplicative Scatter Correction） | 散乱補正。trainの平均スペクトルを基準にする | 未実装                                    |

### 水の吸収ピーク（重要波数帯）

| 波数        | 帰属        |
| ----------- | ----------- |
| 〜8500 cm⁻¹ | OHの第2倍音 |
| 〜6900 cm⁻¹ | OHの第1倍音 |
| 〜5200 cm⁻¹ | OHの結合音  |

## 試した手法と結果

### CV設定の変遷

| バージョン | CV分割単位          | ベイスギ | OOF RMSE（CV） | 提出スコア |
| ---------- | ------------------- | -------- | -------------- | ---------- |
| v1         | sample number       | 含む     | —              | 20.062     |
| v2         | **樹種（species）** | **除外** | —              | 18.092     |
| v3         | 樹種（species）     | 除外     | —              | 23.037     |

### モデル構成

| バージョン | 前処理               | 特徴量              | モデル                            |
| ---------- | -------------------- | ------------------- | --------------------------------- |
| v1         | SNV + PCA(50次元)    | PCA50 + species番号 | LightGBM                          |
| v2         | SNV + PCA(50次元)    | PCA50 + species番号 | LightGBM                          |
| v3         | **SNV + SG 2次微分** | 生スペクトル全波数  | **PLSR**（n_components=CV最適値） |

### 分割方法の考察

- **sample number単位（v1）**: 同一木材の別測定がtrain/valに混在 → 情報リークで楽観的なCV
- **樹種単位（v2/v3）**: 見たことのない樹種へのRMSEを評価 → 実態に近い厳しい評価

### ベイスギ除外の理由

- ユーザー指示により除外
- 汎化の妨げになっている可能性
